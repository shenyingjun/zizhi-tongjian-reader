# ML 辅助 Agent-1 人名跨度标注 POC

状态：已通过评审，采用「试点优先」的概念验证方案。本 POC 不替换
`twostage/rules.py`；它先建立可信的质量测量，也允许最终得出「保留规则」的结论。

## 1. 问题

Agent-1 当前约有 7,000 行 jie 作用域规则，底层模型是文言文 UPOS，而非人名
NER。现有 97.2% 指标只是与含噪 v1 的兼容率，不是真正的精确率/召回率。约
28% 的规则输出不与 v1 重叠，其中同时包含真正补漏和误报。

主要瓶颈是可信标签，而不是模型架构。直接用 v1 训练会把 rules-only 补漏标成
负例 `O`。因此第一交付物是小型人工参考集与可靠评分，而不是模型。

## 2. 范围

- 只处理 Agent 1（人名下划线位置）；Agent 2 身份识别不变。
- 最终输出仍只标正文。
- 胡三省注与译文可为正文提供有界证据，但注文本身不是输出。
- POC 必须能由一位标注者在单块 GTX 1070（8 GB）上完成。
- 不一次性替换规则，不宣称 100% 自动化，不启动全语料规则重建。
- 最终交付物是可独立运行的本地 ML 标注模型。Copilot 只用于开发期加速标签生产，
  不是生产标注器，也不是运行时依赖。

## 3. 证据与标签

候选通道包括 v1、当前规则、段落作用域译文、同 jie 注文投射，以及后续模型。
它们彼此相关，只是候选生成器，不是独立投票，也不是真值。

训练标签采用有界的裁定后并集：

- v1/规则精确一致项可按 `agreement` 来源自动信任。
- 分歧分层抽样审计，上限为训练 3,000、dev 800 个跨度。
- `note-only`、`translation-only` 必须逐跨度人工确认，不能只凭类别策略传播。
- 只有 `human_*` 标签可进入 dev 或密封评估集。

### 3.1 注文与译文护栏

1. **Agent 1 不接触身份数据。** 注文人名在摄入前清洗为
   `{note_index, after, start, end, surface}`；Agent-1 代码从不加载或序列化
   `person_id`。
2. **仅限同一 jie。** 注文证据不得播种其他 jie，也不得形成 juan/语料级人名表；
   注文派生表面始终禁止跨 jie 复用。
3. **译文保持原批准范围。** 段落批准的译文证据在组装 jie 后仍只能作用于原段落。
4. **更早锚点否决。** 注文/译文不能独自授权单字或 given-name 回指；仍必须有
   同一 jie 内更早的正文锚点。
5. **仅几何，不做身份。** 证据只能提示「是人」和边界；注文措辞不成为正文标签。

译文只离线使用。胡三省注属于公有领域源文，因此后期可做默认关闭的运行时
A/B，但不属于当前 P0。

### 3.2 Copilot teacher 与辅助标注闭环

P2 可使用版本化的 Copilot 标注器作为 annotation **teacher**。它的职责是降低人工
标注成本、改进供目标 ML 模型训练的标签语料。Copilot 准确率与目标模型准确率必须
分别测量。

- 已完成的三个试点 juan 可作为边界政策和跨度几何示例；它们是开发上下文，不是
  密封数据。
- teacher 可读取当前整卷全文以理解叙事，但证据授权以 jie 作用域为更高优先级。
  示例表面和其他 jie 上下文不得形成整卷人名表；同卷另一 jie 的相同表面、锚点或
  推断身份不能授权当前候选。每个建议都必须在目标 jie 内成立，且不得读取身份 KB。
- 新的 P2 assisted round 不加载 v1、规则或身份字段。Copilot teacher 可读取当前
  jie 的胡三省注文原文，也可临时读取批准来源的现代汉语译文；译文必须通过已审计
  来源哈希校验，并唯一对齐到当前段落或 jie。译文原文不得写入仓库或 round pack。
- 注文与译文只是证据，不是输出。它们只能在批准作用域内帮助判断正文人物性与姓名
  几何；单字或 given-name 回指仍须同一 jie 内更早正文锚点，任何证据都不得形成
  跨 jie 人名表。
- 候选来源必须记录 Copilot teacher 版本、prompt/示例哈希、注文/译文来源哈希、
  目标 jie 作用域，以及「可见整卷上下文但不得授权」这一事实。保存的 teacher 输出
  只能包含正文候选几何，不能包含注文或译文原文。
- 每轮按完整 juan 隔离：五卷中一卷（20%）为无候选 blind anchor，四卷（80%）为
  Copilot-assisted。blind anchor 完成并永久锁定前，任何 assisted pack 都不得访问。
- Copilot 建议本身不是标签。标注者必须接受、拒绝、修改边界或补充遗漏；只有最终
  人工纠正的跨度可标为 `human_assisted_copilot` 并进入目标模型训练。
- assisted 标签不得进入 dev、blind anchor 或密封评估。blind anchor 保持
  `human_blind_anchor` 来源且只用于评估。

Copilot teacher 的改进闭环为：

1. 冻结 teacher 版本 `N`，只生成一批新的 assisted 数据；
2. 人工审核每个候选，并补出所有发现的遗漏；
3. 冻结纠错结果，计算 teacher 的精确 P/R/F1、重叠诊断、新增、删除及一对一
   几何替换；
4. 按边界政策、单字照应、角色/专称、外族称号、标点及其他预先声明的挑战分层
   归类错误；
5. 只根据已完成的人工纠错修改 teacher 指令与示例，形成版本 `N+1`；
6. 后续 teacher 不得重新生成或覆盖已经完成的批次。

目标模型闭环只摄入人工纠正后的 assisted 标签，训练新的独立模型，并在已锁定的
blind anchor 上评估。teacher 晋升要求它在下一批人工审核数据上的准确率提高；目标
模型晋升则另行要求 blind-anchor 精确 F1 提高且预声明挑战分层不回退。两种晋升都
不能替代后续 P3 密封评估。

## 4. P0 参考集

选取三个 juan：

1. 一个固定种子随机 juan；
2. 一个 rules-v1 精确几何分歧率最高的 juan；
3. 一个 feng、可汗/单于等罕见结构密集的挑战 juan。

标注者首先只看空白正文，完全不知道任何候选。第二遍强制展示候选并集用于补漏。
7–10 天后，对约 10% 的连续 jie 盲重标以测量自一致性。这三个 juan 是试点参考，
不是密封测试集，并从未来密封测试的抽样框中排除。

绑定边界准则采用**有显式姓名时只标姓名核心**：
`赵王[虎]`、`大将军[光]`、`弟[亮]`。爵位、官职和亲属词留在线外；
若只有 `始皇` 等独立专称，该专称本身可作为人物核心。复姓与完整给名仍在线内。
`帝/太后` 等纯角色表达只在当前句法明确指向一个具体人物时标注（`[帝]曰`、
`[太后]怒`）；泛指、类别和授予称号的用法不标，身份由 Agent 2 解析。
这与部分当前规则的完整表达几何有意不同。
可独立识别的人名或个体专称即使嵌在建筑、官署、器物或关系复合词中，仍属于人物
核心，例如 `[汉高]庙`、`[启]母神`。只标人物核心，`庙/府/宫/印` 等载体词留在
线外；机构名中的普通角色词不会仅因此获得授权。
单一命名谓词仍只标结果（`字[季]`、`更名曰[询]`）。若 `姓 X 字 Y` 等连续结构
共同给出当前唯一完整称名描述，而各部分无法独立构成该描述，则标完整表达，例如
`即常安[姓武字仲]`。
并列人物共享右侧称号时，按每个具体人物在原文中实际出现的表面分别标注，包括省略
共享称号的前项：`乌孙[大]、[小昆弥]`、`[广平]、[巨鹿]、[乐成王]`。复数表达
只有在当前 jie 已锚定各成员且明确回指这组具体人物时才标；泛指或未锚定复数角色
仍不标。juan 标题属于元数据而非叙事人物指称，一律不含人物跨度。

## 5. 几何与评估

- 按生产规则相同方式组装编号 jie，以硬分隔符保留段落边界。
- 长序列使用重叠窗口，每个字符只有一个最居中的归属窗口。
- 预测与评分单位仍是一个目标 jie。模型窗口可包含多个周边 jie 作为较弱叙事上下文，
  但非目标字符标签必须为 `-100`、不拥有输出，也不能形成跨 jie 跨度。
- BIO 只允许合法转移；`O` 后的孤立 `I-PER` 提升为 `B-PER`。在没有标点、符号、
  数字、硬分隔符或非归属边界时，train/dev 已固定的结构解码器会把紧邻活动人物
  跨度的 `B-PER` 合并为连续跨度。跨度不得跨硬分隔符或从非归属字符开始/结束。
- 主指标为精确 `[start,end)` PER P/R/F1；重叠 P/R/F1 只作诊断。
- 两者都采用一对一最大匹配，一个长预测不能匹配多个参考跨度。
- 随机与挑战 juan 分开报告，并按结构分层。
- 把完整表达→姓名核心差异单列为**几何替换**，不得混入新增、删除、遗漏或误报。

### 5.1 多 jie 模型上下文

上下文大小由模型 token budget 决定，不固定为 `±1 jie`。先为完整目标 jie 保留空间，
再按距离从近到远填入前后 jie。因此短目标可以看到多个周边 jie，长目标可能只能看到
很少或没有额外上下文。

- 保留明确的段落与 jie 边界，并记录每个上下文 jie 相对目标的有符号距离。
- 上下文可帮助神经模型理解叙事连续性，但不得产生确定性的跨 jie 锚点、表面传播、
  身份解析或输出跨度。
- 先训练和评估 target-jie-only 基线，再比较 target-only、有限邻近上下文和最大
  token-budget 上下文；所有指标只按目标 jie 精确几何计算。
- 上下文构造与 checkpoint 选择只能使用训练集和 challenge dev 固定；不得根据随机
  试点 holdout 或密封集选择上下文大小。
- 根据实际上下文图建立对称 guard band。任何训练窗口都不得包含 dev 目标文本，
  即使只是上下文；dev 窗口中可见的 jie 也不得作为训练目标。必须报告 guard-band
  排除项。
- 先使用现有 Transformer。只有有限 Transformer 上下文已证明有效且 512-token
  限制确实成为瓶颈时，才 A/B 测试 LSTM、层次 Transformer、Longformer 等架构。

Tier-1 只能鼓励或证伪：随机 juan 的精确 F1 比规则低超过 3 点、遗漏恢复低于
25%，或挑战补漏无补偿回退时停止；精确 F1 在规则约 2 点以内或更高、恢复至少
50% 已确认遗漏且无系统性新误报类别时，才进入下一阶段。

只有后续密封概率样本及 bootstrap 置信区间能支持采纳。混合采纳还要求模型精确
F1 不低于规则、挑战分层下降不超过 5 点，并且自动发布层的精确率单侧 95% 下界
至少为 0.98。

### 5.2 P3 密封集

在任何 P3 模型推理前，冻结五个从未使用过的完整 juan：

- 从合格的 1–294 抽样框中，以固定种子无放回均匀抽取三卷；
- 从预先声明的角色/专称正文词频最高五卷中密封抽取一卷；
- 从预先声明的外族称号正文词频最高五卷中密封抽取一卷。

排除所有曾用于训练、开发、试点 holdout、blind anchor 评估、assisted 标注或已
废弃/泄露密封集的 juan。概率样本与挑战卷都使用私有随机种子抽取；私有 manifest
必须冻结该种子、选定模型哈希、checkpoint 选择记录、选择政策、任务/来源哈希和
当前代码提交。标注任务文件只能包含无候选正文及段落/jie 几何；每卷完成并永久
锁定前，UI 不得泄露其选择角色。五卷参考标签全部锁定前，不得生成模型或规则预测；
P3 失败案例不得用于选择或重训被评估模型。

## 6. 若 P0 支持继续：模型

P1 朴素挑战者使用
`KoichiYasuoka/roberta-classical-chinese-base-char` 与
`AutoModelForTokenClassification`，标签为 `{O,B-PER,I-PER}`。从一开始使用
jie 组装与约束式解码，但不加入自训练、agent 自动标签、遗漏恢复、覆盖层、
校准或运行时注文。

P2 Copilot teacher 不改变上述 P1 模型定义：未经人工审核的 agent 输出永远不能
训练目标模型；后续训练轮只能加入人工纠正后的 assisted 跨度。

初始 P1 计时基线仍为 target-jie-only。多 jie 软上下文属于独立的 P2 目标模型 A/B，
必须保持只在目标 jie 计算 loss、输出和评分。

使用独立 CUDA 环境；先在 GTX 1070 上测一个 epoch 和完整推理，再承诺时间。
预期使用 FP32 微批与梯度累积；large 模型不在范围内。

## 7. 阶段

- **P0（3–5 天）：** 三个 juan、盲标、候选补漏、自一致性子集、精确匹配器、
  约束解码器、规则真实基线。
- **P1（3–5 天）：** 有界裁定标签与朴素 char-BIO 挑战者。
- **P2：** 停止、投资真正评估集，或通过版本化 Copilot teacher 扩大试点；每四个
  assisted juan 配一个 blind anchor，分别改进 teacher 标注效率与独立目标模型。
- **P3（仅当结果鼓舞）：** 密封概率样本与挑战集。
- **P4+（仅当 Tier-2 通过）：** 校准、遗漏通道、注文运行时 A/B、留出表面研究、
  多种子方差和混合部署。

## 8. 风险

- 银标偏差：使用裁定标签，不直接使用 v1。
- 长尾不可见：维护非流行度加权挑战集。
- 测试污染：密封测试失败案例不得回灌训练。
- 上下文泄漏：必须在上下文闭包完成后再划分 split；训练与 dev 窗口不得通过周边
  jie 上下文看到对方的目标文本。
- teacher 污染：blind anchor 锁定前不得展示候选；assisted 标签不得进入 dev；
  不得把跨 jie 示例表面当作当前 jie 人物证据。
- 自动化偏差：记录所有 Copilot 接受、拒绝、边界修正和人工补漏；teacher 输出
  不是真值。
- 单一标注者：报告延迟盲重标自一致性，不冒充共识。
- 作用域/身份泄漏：预清洗注文、保持译文段落范围、执行同 jie 更早锚点规则，
  note/translation-only 逐跨度确认。
- 算力超支：先测量再安排计划。
- 劳动只是转移：比较标注/审阅与规则编写成本；POC 可以合理选择保留规则。
