# P0 人物跨度边界准则（已确认）

状态：**所有者于 2026-07-26 确认。** 本准则只决定 Agent 1 的下划线几何，
不决定人物身份。P0 采用「有显式姓名时只标姓名核心」策略。

## 总原则

1. 表达中存在显式姓名时，只标**姓名核心**；官职、爵位、政权主号和亲属词留在线外。
2. 不因「知道此人是谁」而扩张或缩短边界；只依据当前文本。
3. 标点、引号、圈号、普通动词及句法助词永不进入跨度。
4. 同一处不能有重叠或嵌套的两个人物跨度。
5. 有疑义时先不标，并记录问题；第二遍候选补漏时再裁定。

## 应当标注

| 类型 | 边界 | 例 |
|---|---|---|
| 姓名 | 完整姓（含复姓）+完整名 | `[曹操]`、`[诸葛亮]`、`[慕容垂]` |
| 封号/政权主号+名 | 只标姓名核心 | `赵王[虎]`、`淮南王[生]`、`燕主[垂]` |
| 官职+名 | 只标姓名核心 | `大将军[光]`、`左将军[桀]` |
| 亲属词+名 | 只标姓名核心，即使中间夹官职 | `弟[亮]`、`其子[仁果]`、`弟…左将军…[亮]` |
| 外族姓名+称号 | 只标姓名核心 | `[佗钵]可汗`、`柔然可汗[阿那瓌]` |
| 姓名+后妃/公主称谓 | 有可分姓名时只标姓名核心 | `[萧淑]妃`；无独立姓名核心的 `[太平公主]` 单独裁定 |
| 明确定义的字、号、改名 | 被定义的人物称名 | `字[季]`、`号曰[犀首]` |
| 同 jie 省称 | 仅省称本身；必须有更早正文锚点 | `[曹操]…[操]曰` |
| 无显式姓名的专称 | 专称本身就是人物核心时标完整专称 | `[始皇]`、`[周世宗]` |
| 无显式姓名的角色回指 | 仅当同一 jie 正文能把角色定位到一个具体人物时标完整角色词；身份交给 Agent 2 | `[霸]…[丞相]奏`、`[帝]曰`、`[太后]怒` |
| 稳定人物称号 | 后续独立用于指称具体人物时标完整称号 | `[屠耆单于]使…`、`[冯夫人]上书` |
| 姓名、字、号的定义 | 命名谓词的结果仍是人物称名，应标 | `更名曰[询]`、`号曰[冯夫人]` |

## 不应标注

- 泛指、类别或复数角色：`古之帝王`、`群臣`、`博士`（泛指一类官员）。
- 官署、宫室、制度或职位本身：`丞相府`、`太子宫`、`皇帝位`。
- 授官、册立、自立等谓词所赋予的角色：`尊母为太后`、`立为屠耆单于`、
  `段会宗为都护` 中的新头衔；只有后续独立指向具体人物时才标。
- 纯称呼代词或敬称：`陛下`、`足下`。
- 固定作者/史家署名：`臣光曰`、`班固赞曰` 中的作者名；评论正文内部提到的历史人物仍标。
- 同一 jie 内没有姓名、称号或明确叙事锚点可定位的普通官职：孤立的 `丞相司直奏`、
  `都护奏` 等。它们虽由人执行，但不进入本人物回指层。
- 政权、族群、地名、军镇、年号、干支或普通名词。
- 更长**姓名核心**的一部分：不得把 `沙漠汗` 切成 `漠汗`；但应把
  `赵王虎` 按本策略标为 `赵王[虎]`。
- 没有更早同 jie 正文锚点的单字/给名回指；注文或译文不能替代该锚点。
- 注文中的人名本身；注文只用于第二遍正文候选裁定。
- 从后文身份反推前文边界，或从另一个 jie 继承人名。

## 边界冲突处理

- **最长完整姓名核心优先**，但不得吞入官职、爵位、亲属、地点、谓词或标点。
- 若整句只有称号/角色而无显式姓名，以**同一 jie 能否定位到一个具体人物**为准：
  有更早正文锚点的 `[丞相]奏` 可标；无法在本 jie 定位的 `丞相司直奏`、`都护奏`
  不标。不得从另一 jie、juan 级名册或身份 KB 补足锚点。
- 复合官职只有在先满足同 jie 定位条件时才标；一旦可标，应取完整边界，
  不得把 `丞相司直` 拆成 `[丞相]司直`。
- `号曰/更名曰/字` 是称名定义，结果应标；`立为/拜为/尊为/自立为` 是角色授予，
  结果不标。相同头衔在后文转为具体人物指称时应标。
- v1、规则、译文或注文与本准则冲突时，以人工阅读和本准则为准。
- 无法确定是完整称谓还是普通描述时，标为 `ambiguous` 并写简短说明，不强行决定。
- 第二遍修改第一遍跨度时，系统必须保留修改来源与原几何。

## 已确认的绑定决定

1. `赵王[虎]`。
2. `大将军[光]`。
3. `弟[亮]`；若写作 `弟 XXX 亮`，仍只标 `[亮]`。
4. 后续省称 `[虎]/[光]/[亮]` 要求同一 jie 内更早的正文锚点。
5. `帝/太后` 等角色词只在当前用法明确回指具体人物时标注；Agent 1 只画线，
   Agent 2 再解析身份。

这与当前生产规则偏好的完整表达几何有意不同。评估必须把
`[赵王虎] → 赵王[虎]` 等记为**边界替换**，不得称为人物遗漏或新增人物。
